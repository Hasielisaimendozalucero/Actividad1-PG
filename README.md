## Descripción

Se presentan los ejercicios prácticos trabajados en clase, abarcando conceptos de HTML,CSS según las indicaciones de cada práctica.

## Contenido del Repositorio

index.html: Archivo principal que actúa como menú de navegación para acceder a cada ejercicio.
CSS: Carpeta que contiene los estilos visuales de las páginas.
img: Carpeta destinada a las imágenes utilizadas.
js: Carpeta reservada para los scripts de JavaScript.
